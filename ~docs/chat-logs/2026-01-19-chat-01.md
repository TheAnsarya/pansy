## Technical Notes

### Binary Format
```
Header: "PANSY\0\0\0" (8 bytes magic)
        uint16 version (0x0100)
        byte platform (0x01 = NES, etc.)
        byte flags (0x01 = compressed)
        uint32 romSize
        uint32 romCrc32

Sections: (each has section ID + compressed size + uncompressed size + data)
        - Metadata (0x01)
        - Symbols (0x02)
        - Comments (0x03)
        - CodeOffsets (0x04)
        - DataOffsets (0x05)
        - JumpTargets (0x06)
        - SubEntryPoints (0x07)
        - MemoryRegions (0x08)
        - CrossReferences (0x09)
```

### Platform IDs
- 0x01: NES (6502)
- 0x02: SNES (65816)
- 0x03: Game Boy (Z80-like)
- 0x04: Game Boy Advance (ARM7TDMI)
- 0x05: Sega Genesis (68000)
- 0x06: Atari 2600 (6507)
- 0xFF: Custom

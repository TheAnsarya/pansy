## Recommendations Documented

- Prefer uncompressed Pansy files for latency-sensitive repeated load paths; compressed files are better for storage/transfer footprint.
- Reuse loaded `PansyLoader` instances across analyzer/validator passes instead of reparsing for each query.
- Run `ValidateJumpGraph` as a fast preflight integrity pass before heavier analysis/pattern workflows.
- Keep CDM density focused on high-confidence code/data regions to avoid unnecessary memory amplification in very dense graphs.

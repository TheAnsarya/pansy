**Extracted and unified Pansy format code:**
- `PansyLoader.cs` - Read Pansy files (from Peony)

- `GlobalUsings.cs` - Global using directives

**Features:**
- Read/write binary .pansy files
- Support for all platforms (NES, SNES, GB, GBA, Genesis, Atari 2600, Custom)
- Symbols, comments, code/data maps, cross-references, memory regions
- Optional DEFLATE compression
- .NET 10 / C# 14

### 3. CLI Application (Pansy.Cli) ✅
**Created command-line tool:**
- `info` command - View Pansy file contents
- Uses Spectre.Console for rich terminal output
- Displays header, statistics, memory regions, symbols (with --verbose)
- Simple argument parsing (no heavy dependencies)

**Example usage:**
```bash

pansy info file.pansy --verbose  # Show symbols too
```

## Technical Details

### Namespace Changes
- Poppy: `Poppy.Core.CodeGen.PansyGenerator` → `Pansy.Core.PansyWriter`
- Peony: `Peony.Core.PansyLoader` → `Pansy.Core.PansyLoader`

### PansyWriter Refactoring
- Removed dependencies on Poppy's `SymbolTable`, `TargetArchitecture`, `OutputSegment`
- Created standalone API with `AddSymbol()`, `AddComment()`, `MarkAsCode()`, etc.
- Simplified generator to use dictionaries and sets directly
- Maintains same binary format as Poppy's generator

### CLI Implementation
- Initially tried System.CommandLine 2.0 (API changed significantly)
- Switched to simple switch-based routing for reliability
- Uses Spectre.Console for tables and formatting
- Returns proper exit codes

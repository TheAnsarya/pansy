## Lynx Memory Regions

| Region | Address | Type | Description |
|--------|---------|------|-------------|
| Zero Page | $0000-$00ff | RAM | Fast access |
| Stack | $0100-$01ff | RAM | 6502 stack |
| Work RAM | $0200-$fbff | WRAM | Program/display |
| Suzy | $fc00-$fcff | IO | Sprite/math |
| Mikey | $fd00-$fdff | IO | Timer/audio |
| Boot ROM | $fe00-$ffff | ROM | Bootstrap |
